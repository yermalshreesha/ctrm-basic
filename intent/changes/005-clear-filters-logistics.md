# Change: Clear filters button on the Logistics list
Requested by: Yermal Udaya Shreesha   Date: [26-10-2026]
Status: in progress

## What they asked for
Same as change 004, for the Logistics list: after filtering
shipments, resetting means changing each dropdown back to "All" by
hand. Users want one button to clear them.

## Details
- A "Clear filters" button in the Logistics list's filter row,
  before any other actions.
- Clicking it resets both filters (status and warehouse) to "All",
  and shows all shipments again.
- The button only shows when at least one filter is active.
- Same behavior and style as the Trades list button (change 004):
  secondary button, no confirmation, visibility based on the URL.

## Affects existing
Only the Logistics list screen. No backend or data changes.

## Out of scope
- Clear filters on other screens (Inventory, Dashboard).
- Changing the Trades list button from change 004.

None.
